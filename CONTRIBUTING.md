# Contributing to WiFiScan

Thank you for helping improve WiFiScan.

## Scope

WiFiScan is a **defensive** utility for inspecting Wi-Fi security and encryption information. Contributions must remain non-destructive and must not enable offensive capabilities.

## Standards

- Prefer small, focused changes
- Keep the tool educational and defensive
- Never commit secrets or sensitive network data
- Update documentation when behavior changes
- Keep all project content in English

## Validation

Before opening a pull request, test the relevant flow and confirm the change does not expand the tool beyond defensive inspection.

## Security

Follow the process in [SECURITY.md](SECURITY.md).
